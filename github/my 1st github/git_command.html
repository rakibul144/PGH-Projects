যদি branch-এর নাম main না হয় git remote add origin git push -u origin main এই কাজগুলো জীবনে একবারই করতে হয় একটি Project-এর জন্য। পরিস্থিতি ২: একই Project-এ পরের দিন আবার কাজ করতে বসলে ধরো আজ Project বন্ধ করলে। আগামীকাল আবার VS Code খুলে একই Project-এ কাজ করবে। তখন git init বা git remote add origin আবার করতে হবে না। শুধু: Project Folder খুলবে। কোড লিখবে। তারপর: git add . git commit -m "What you changed" git push 🟢 নতুন Project (একবার) Project তৈরি ↓ git init ↓ git add . ↓ git commit -m "Initial commit" ↓ git remote add origin ↓ git branch -M main ↓ git push -u origin main 🔵 একই Project-এ প্রতিদিন Project খুললাম ↓ (প্রয়োজনে git pull) ↓ Code লিখলাম ↓ git add . ↓ git commit -m "Describe changes" ↓ git push 🎯 মনে রাখার সহজ নিয়ম একটি নতুন Project-এর জন্য: git init → git remote add origin → git push -u origin main একবারই। প্রতিদিনের কাজের জন্য: git add → git commit → git push বারবার। এটাই বাস্তবে বেশিরভাগ ডেভেলপারদের দৈনন্দিন Git workflow।
